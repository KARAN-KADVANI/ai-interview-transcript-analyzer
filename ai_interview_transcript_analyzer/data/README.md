# Dataset folder

Put the Kaggle CSV here.

**Dataset:** Software Engineering Interview Questions Dataset (by syedmharis)
**Link:** https://www.kaggle.com/datasets/syedmharis/software-engineering-interview-questions-dataset
**File needed:** `Software Questions.csv`

Columns: `Question Number`, `Question`, `Brief Answer`, `Category`, `Difficulty`
(250 questions, 11 categories).

After copying the file here, run `python train.py` from the project root.
